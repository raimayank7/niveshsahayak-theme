# niveshsahayak-theme

Website files for [niveshsahayak.in](https://www.niveshsahayak.in/), served at `https://assets.niveshsahayak.in/assets/`.

| File | What it does |
|---|---|
| `assets/ns.css` | Styles for the language switcher, articles, popular posts, 404 page and the "Invest with me" card |
| `assets/ns.js` | Language system (English, हिन्दी, ਪੰਜਾਬੀ, भोजपुरी + Google Translate), article extras, SEO data, "Invest with me" popup |

The Blogger theme loads these files with a version number that changes every 10 minutes, so a push reaches visitors quickly. If the main address can't be reached, the theme falls back to jsDelivr.
